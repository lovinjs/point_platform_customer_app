# 消费者端主题体系

## 设计方向

当前主题命名为“低空科技蓝”。深海军蓝体现可靠与专业，飞行蓝承担主要品牌识别，少量青色用于表现数字化与空间感。主题不直接模仿任何无人机品牌，以便逐步形成平台自己的视觉资产。

## 颜色语义

- 品牌蓝：主按钮、选中态、链接、主视觉卡片和功能图标。
- 青色：只作为品牌渐变的辅助色，不单独表达业务状态。
- 成功绿：仅用于充值到账、消费完成、成功状态等正向结果。
- 提醒黄：用于账户提醒、锁定提示和需要用户注意的信息。
- 风险红：用于失败、扣减和不可逆操作等风险信息。
- 中性灰蓝：正文、次要文字、边框、背景和未选中状态。

## 文件职责

| 文件 | 用途 |
| --- | --- |
| `src/styles/theme.scss` | CSS 语义变量、渐变、阴影及 Wot UI 主题映射 |
| `src/config/theme.ts` | 组件属性、Canvas 和平台 API 无法直接使用 CSS 变量时的颜色常量 |
| `src/uni.scss` | uni-app 编译期的基础颜色变量 |
| `src/pages.json` | 原生导航栏、页面背景和底部导航颜色 |
| `src/static/tabbar/` | 与原生底部导航配套的蓝色、灰蓝色静态图标 |

## 使用约定

1. 页面样式优先使用 `--app-color-*`、`--app-gradient-*` 和 `--app-shadow-*`，不要重复写品牌色值。
2. Vue 组件的 `color`、`bg-color` 等属性从 `themeColors` 读取。
3. 绿色不能作为普通品牌装饰色使用，以免与“交易成功”混淆。
4. 调整品牌色时，需要同步检查 `theme.scss`、`theme.ts`、`uni.scss`、`pages.json` 和底部导航图片。
5. 新增颜色前先判断它是品牌、状态还是中性色；只有现有语义确实不能表达时才扩展变量。
